# Student Task & Assignment Tracker

A secure web application for students to manage study tasks, assignments, priorities, and deadlines with user accounts powered by Supabase.

## Tech Stack
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Backend / Auth / DB**: Supabase (PostgreSQL + Auth)
* **Hosting**: Netlify
* **Version Control**: Git & GitHub

## Setup & Deployment
1. Create a project in **Supabase**, run the script inside `schema.sql` in the SQL Editor.
2. Copy your Supabase Project URL and Anon Public Key into `app.js`.
3. Open in **VS Code**, initialize Git, and push your repository to **GitHub**.
4. Import the repository into **Netlify** for live deployment.
